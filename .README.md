Group 2 Assignment Spec – Role Based Admin
Panel System
Objective
Build a role-based admin panel system using configuration-driven architecture. Focus on
authentication flow, route protection, and permission-based rendering.
Authentication Requirements
• Login page with username and role selector.
• Roles: Admin, Manager, Analyst.
• Persist session using localStorage.
• Logout functionality with state reset.
Role Based Access Control
• Protected routes using React Router.
• Unauthorized access redirection.
• Access denied page.
• Prevent manual URL bypass.
Config Driven Navigation
• Sidebar generated from navigation config file.
• Role-based visibility rules.
• Support nested routes.
• Active route highlighting.
• Collapsible sidebar.
Feature Flags System
• Create feature configuration file.
• Enable or disable modules dynamically.
• Feature flags must affect both UI and route access.
Global State Requirements
• AuthContext implementation.
• Custom hook for auth logic.
• Global notification system.
• Proper state cleanup on logout.
Technical Constraints
• Functional components only.
• Minimum 2 custom hooks.
• No deeply nested conditionals in JSX.
• Separation of config and UI logic.
• Clean folder structure.
Deliverables
• GitHub repository link.
• Detailed README explaining role architecture.
• Permission validation explanation.
• Feature flag mechanism explanation.
Evaluation Criteria
• Architecture clarity – 30%
• Role validation logic – 20%
• Routing correctness – 20%
• Code cleanliness – 15%
• Feature flag implementation – 10%
• UI quality – 5%
